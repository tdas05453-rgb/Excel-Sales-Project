# Qlik360 Hardware Sales & Performance Analysis

**Project Overview**
This project analyses **customer sales performance and market performance against targets** using the Qlik360 Hardware dataset.

### 🎯 Objectives

* Analyse customer-wise sales performance.
* Compare sales across different years.
* Analyse market-wise performance.
* Compare actual sales with the 2021 target.
* Identify performance gaps and business insights.

### 📌 Analysis Performed

**1. Customer Performance Report**

* Analysed customer-wise net sales from **2018–2021**.
* Compared customer sales performance.
* Identified changes in sales performance between 2020 and 2021.

**2. Market Performance vs Target**

* Analysed market-wise net sales.
* Compared **2021 actual sales vs target**.
* Identified target gaps and market performance.
